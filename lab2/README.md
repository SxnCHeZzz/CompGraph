# Лабораторная работа №2

Три задания запускаются независимо друг от друга. Нужен Python 3.10 или новее.

## Запуск

Откройте терминал в папке `CompGraph/lab2`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python task1.py
python task2.py
python task3.py
```

В Windows активация окружения: `.venv\Scripts\activate`.
Без аргументов используется тестовое изображение `sample.png`.
Можно указать своё изображение:

```bash
python task1.py "photo.jpg"
python task2.py "photo.jpg"
python task3.py "photo.jpg" --output "result.png"
```

Для окон и ползунков запускайте скрипты в обычной графической среде.

## Задания

- `task1.py` — два полутоновых изображения, их абсолютная разность и две гистограммы. Формулы: `0.299R + 0.587G + 0.114B` и `0.2126R + 0.7152G + 0.0722B`. Презентация не предоставлена: при необходимости замените коэффициенты в `to_grayscale`. Формулы применяются непосредственно к значениям RGB от 0 до 255, без линеаризации. Результаты округляются до целых. Разность показывается без усиления контраста, поэтому может выглядеть тёмной.
- `task2.py` — каналы R, G, B на отдельных изображениях и три гистограммы интенсивности. Для выделения канала остальные два обнуляются.
- `task3.py` — собственные преобразования RGB → HSV и HSV → RGB. H задаётся в градусах, S и V — от 0 до 1. Ползунки добавляют сдвиг к исходным значениям: оттенок по кругу, насыщенность и яркость с ограничением диапазона. Кнопка «Сбросить» возвращает оригинал, «Сохранить» записывает результат в RGB. По умолчанию — `results/task3/edited.png`; повторное сохранение заменяет файл.

Первые два скрипта сохраняют картинки и общие рисунки с гистограммами в `results/task1` и `results/task2` рядом со скриптами. Повторный запуск заменяет эти результаты. Прозрачность входного изображения не сохраняется.
