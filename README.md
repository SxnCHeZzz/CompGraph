# Компьютерная графика

Откройте папку `COMPGRAPH` в VS Code. Команды **Run Python File** и **Run Code**
используют общее окружение `.venv` в корне репозитория. Для ЛР7–9 можно также
открыть папку отдельной лабораторной.

## Настройка на macOS

В новом клоне выполните один раз из корня репозитория, используя Python с Tkinter.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Для запуска из обычного терминала используйте интерпретатор окружения напрямую.

```sh
.venv/bin/python lab9/interface.py
```

Чтобы использовать команду `python` в открытом терминале, активируйте окружение
командой `source .venv/bin/activate` из корня репозитория. При переходе в папку
лабораторной в этом терминале окружение останется активным.
