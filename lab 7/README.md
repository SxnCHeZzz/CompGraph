# Лабораторная работа №7. Построение трёхмерных моделей

## Запуск

Сохраните папки `lab 6` и `lab 7` рядом. Для запуска на macOS через ▶ в VS Code откройте папку `lab 7` и один раз выполните в её терминале эти команды, используя Python с Tkinter.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Откройте `interface.py` и нажмите ▶. Code Runner запускает файл через Python из `.venv`.

## Что переиспользовано из Lab 6

- Представление многогранника вершинами и гранями, вывод рёбер и пять правильных многогранников.
- Перенос, масштабирование, отражение и вращение вокруг координатной оси или прямой A–B с помощью матриц 4×4.
- Каркасное отображение, аксонометрическая и перспективная проекции, управление обзором.

Модуль `lab6_base.py` подключает эти компоненты из соседней папки `lab 6`.

## Что показать на защите Lab 7

1. Откройте любой OBJ из папки `models`, сместите модель и сохраните её. При повторном открытии виден результат преобразования.
2. Задайте точки образующей, ось X, Y или Z и число разбиений N. Программа вращает образующую с шагом 360°/N и соединяет соседние кольца гранями.
3. Выберите функцию z = f(x, y), диапазоны и число разбиений по каждой оси. Программа вычисляет высоты в узлах сетки и создаёт по четырёхугольной грани на ячейку.

Фигуру вращения и график также можно преобразовать, сохранить в OBJ и снова открыть.
